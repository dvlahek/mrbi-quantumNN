# Related Numerical Algorithms article

The multiscale residual-detector idea used in this repository is related to the following accepted/published work:

Vlahek, D. *A hybrid gaussian–wavelet multiscale algorithm for zero localization in oscillatory functions*. Numerical Algorithms (2026). https://doi.org/10.1007/s11075-026-02484-8

That article studies a scale-normalized Gaussian-wavelet zero-localization method for oscillatory scalar functions and supports its use as a preprocessing stage for basin identification and initialization of classical root-finding methods. The present repository uses the same broad numerical idea in a different setting: instance-specific initialization of a classical implicit equilibrium feature layer before a simulated QNN readout.
