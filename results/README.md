# Reproducibility results

Tracked aggregate results for the final fixed protocols:

- `final/confirmation_summary.json` — confirmation statistics and provenance.
- `final/confirmation_dataset_summary.csv` — confirmation results by dataset.
- `final/rho_overall_summary.csv` — spectral-radius sensitivity summary.
- `final/rho_dataset_summary.csv` — spectral-radius sensitivity by dataset.
- `final/classical_overall_summary.csv` — classical-readout summary.
- `final/classical_dataset_summary.csv` — classical-readout results by dataset.

Per-seed outputs are regenerated by the scripts under `scripts/` and are not tracked on `main`.

The fixed dataset-specific MRBI profile map is stored in `experiments/selected_profile_confirmation_lock_v1.json`. Full development history is preserved on the archive branches listed in the repository README.
